# Desert Air Heating & Cooling

A professional, responsive website for a family-owned local HVAC company. The site presents services, customer trust signals, company story, reviews, and a simple estimate-request experience.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The company name, phone number, license number, reviews, and service details are polished sample content and should be replaced with the business's real information before launch.
